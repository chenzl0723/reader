# 2026-11-10

## 部署适配（GitHub + Render）

背景：reader 项目（Vue SPA + Express 单进程）需托管到线上，用户无服务器，选择 GitHub + Render 路线。

应用形态结论：Express 中台同时提供 `/api`、`reader/` 静态页、30s 域名健康检测定时任务 → 必须部署为监听 `$PORT` 的常驻 Node 服务，不能只传静态产物。

改动：
- `server/index.js`：静态目录双挂载 `app.use('/reader', static)` + `app.use(static)`，兼容根域名（Render）与 `/reader/` 子路径（nginx）两种形态。
- `vite.config.js`：`base: process.env.VITE_BASE || '/reader/'`，根域名部署时用 `VITE_BASE=/` 构建。
- `package.json`：`ioredis` 从 dependencies 移到 optionalDependencies，加 `engines.node >= 18`（托管平台预检会把 Redis 驱动判为需外部服务而拒启动）。
- `server/services/domainPool.js`：`import('ioredis')` 改动态导入，缺失即降级内存域名池。
- 新增 `render.yaml`（Singapore / free / `npm ci && npm run build` / `node server/index.js`）与 `DEPLOY.md`。

验证：本地 `PORT=3110 VITE_BASE=/ node server/index.js`，`/`、`/reader/`、`/static8/*`、`/go`、`/api/generate-link`、`/api/resolve` 均 200；无 Redis 时日志降级正常。

注意：`nginx/gateway.conf` 在会话期间被外部删除，已 `git restore` 恢复。仓库 remote 是 gitee（Render 不支持，需转 GitHub）。

## 改为纯静态部署（用户决定）

用户明确只要静态托管，不跑 Node 服务。变更：
- `render.yaml` 改为 `runtime: static`：`staticPublishPath: ./reader`、`VITE_BASE=/`、`/*→/index.html` rewrite、`/static8/*` 长缓存。
- `DEPLOY.md` 重写为静态部署流程（含 Render Static Site 参数表与自查命令）。
- 构建方式：`VITE_BASE=/ npm run build`，产物 `reader/`。

功能边界（重要）：主落地页 `/go`、`/mine/focusCode` 取外部接口 `https://97api.szinfohub.cn/app-api/system/business-domain/get-active`，静态下正常；`/switch` 页 `fetch('/api/resolve')` 在纯静态下无接口，会无限重试卡在加载态。
若走纯静态，项目里 `server/` 与 express 相关依赖仅保留给本地或服务器部署，不再参与线上链路。

## 页面合规化改造（对照微信外部链接内容管理规范 2025-10-23 版）

用户要求"符合微信规则、保留原业务逻辑"。识别并清除的违规点：
- `官方正品授权 · 安全合规通道`、`星月汇安全网关认证` → 仿冒官方背书（2.6.3 / 2.16.2）
- `SSL 256位加密通道已建立`、`端到端 TLS 1.3`、`金融级传输加密` → 文案与实际不符（2.3.2）、虚假服务信息（2.6 / 2.9）
- `/guide` 的"点击右上角菜单 → 在浏览器打开"箭头指引 → 规避平台管控（3.2.2）、限制浏览渠道（3.2.3）
- `isRiskEnvironment()` 按 UA 判定微信并跳转 → 微信内外展示不一致（3.2.3），改为只认 `force_external=1`
- `/switch` 无限轮询卡加载态 → 改为最多 5 次重试后给出失败提示与重试按钮（2.9）

保留的业务逻辑：URL 参数解析（含 b/d/s 简写）、分销关系 localStorage+Cookie 持久化、域名池接口 `active_landing` 取数、`countdown_seconds` 配置、按 scan 选择 index/detail 路由、参数透传 + t/token、倒计时跳转；`/switch` 仍走 `/api/resolve` 后 `location.replace`。

其他：`IGNORED_PARAMS` 增加 `force_external` 避免透传到目标 URL；logo 改用 `import.meta.env.BASE_URL`；两页加滚动兜底防矮屏裁切。
验证：`VITE_BASE=/ npm run build` 通过，产物 JS 中 10 个违规文案 grep 全部清零。
